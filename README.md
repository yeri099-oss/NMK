# 🍚 한식페스타 매출 앱

국립중앙박물관 한식페스타(2026.10.23 금 ~ 10.24 토) 판매용 매출 앱입니다.
파일 하나(`index.html`)로 동작하고, 데이터는 파이어베이스(`trip-84bd3`)에 실시간으로 저장돼서 여러 기기에서 같은 매출을 함께 볼 수 있어요.

## 처음 한 번만 하는 설정

### 1. 파이어베이스 규칙 넣기 (복사 도우미)
1. `https://yeri099-oss.github.io/NMK/rules.html` 접속 (앱 [관리] 탭에도 버튼 있음)
2. **📋 복사하고 규칙 화면 열기** 클릭 → 전체 규칙이 복사되고 파이어베이스 규칙 화면이 열림
3. 규칙 편집창 클릭 → `Ctrl+A` → `Ctrl+V` → **게시**

> `firestore.rules` = 기존 앱 규칙 전체 + 한식페스타(`festaApp_*`) 규칙. 기존 앱 규칙은 그대로예요.
> 규칙을 고치면 `python3 build-rules-page.py` 로 `rules.html` 을 다시 만들어 주세요.

### 2. 깃허브 페이지로 공개
1. 이 저장소 → **Settings → Pages**
2. Source: `Deploy from a branch`, Branch: `main`(또는 이 작업 브랜치) / `/ (root)` → Save
3. 1~2분 뒤 `https://yeri099-oss.github.io/NMK/` 주소로 접속

### 3. 최초 로그인
- 관리자 아이디 `goodbab` 과 정해둔 관리자 비밀번호로 로그인하면 관리자 계정이 자동으로 만들어지고,
  기본 상품 5가지(귤당근쥬스, 레몬즙, 김부각, 새송이부각, 보자기카스테라)가 자동으로 등록됩니다.
- 일반 계정은 **[관리] 탭 → 계정 관리**에서 만들어 주세요.

## 화면 구성

| 탭 | 기능 |
|---|---|
| **판매** | 상품 수량 선택 → 합계 자동 계산, 할인(원/%), 결제방식(카드/현금/제로페이), 현금 받은 돈 → 거스름돈, 고객정보(한국인/외국인, 여성/남성 — 선택사항), 비고. **초기화**로 비우고, **판매 등록**으로 확정 |
| **상품정보** | 사진·설명·가격을 한국어/English로 보기. 카드를 누르면 고객에게 보여주기 좋은 큰 화면(좌우로 넘기기) |
| **대시보드** | 전체 합계 / 10.23 / 10.24 별 매출·건수·수량·객단가, 상품별 판매수량·매출, 결제방식별, 시간대별, 고객 국적·성별 |
| **판매내역** | 제목 누르면 오름차순/내림차순 정렬, 검색(상품·금액·결제방식·비고·판매자·외국인 등 무엇이든), 줄을 누르면 수정·삭제, 엑셀(CSV) 받기 |
| **관리** (관리자만) | 상품 추가·수정·삭제(사진 업로드 포함), 계정 만들기·권한 변경·사용중지, 연습 데이터 정리 |

## 알아두면 좋은 점
- **인터넷이 잠깐 끊겨도 판매 등록이 됩니다.** 기기에 먼저 저장되고, 연결되면 자동으로 올라가요 (판매내역에 "업로드 대기" 표시). 단, 업로드 전에 그 기기의 앱을 지우거나 브라우저 데이터를 삭제하면 안 돼요.
- 행사 전에 연습한 판매는 대시보드의 **행사일 외**로 따로 보이고, [관리] → **행사일 외 판매내역 삭제**로 한 번에 지울 수 있어요.
- 상품별 매출은 **정가 기준**이고, 할인은 합계 아래에 따로 빠져서 **실매출**로 표시돼요.
- 상품 설명은 초안이에요. [관리] → 상품 **수정**에서 실제 내용으로 고쳐주세요.
- 사진은 자동으로 줄여서 저장돼요(파이어베이스 Storage 불필요).
- 일반 계정 비밀번호를 잊으면 사용중지 후 새 아이디로 만들어 주세요.
