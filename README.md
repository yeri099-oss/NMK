# 🍚 한식페스타 매출 앱

국립중앙박물관 한식페스타(2026.10.23 금 ~ 10.24 토) 판매용 매출 앱입니다.
파일 하나(`index.html`)로 동작하고, 데이터는 파이어베이스(`trip-84bd3`)에 실시간으로 저장돼서 여러 기기에서 같은 매출을 함께 볼 수 있어요.

## 처음 한 번만 하는 설정

### 1. 파이어베이스 규칙 넣기 (복사 도우미)
1. `https://yeri099-oss.github.io/NMK/rules.html` 접속 (앱 [관리] 탭에도 버튼 있음)
2. **📋 복사하고 규칙 화면 열기** 클릭 → 전체 규칙이 복사되고 파이어베이스 규칙 화면이 열림
3. 규칙 편집창 클릭 → `Ctrl+A` → `Ctrl+V` → **게시**

> `firestore.rules` = 기존 앱 규칙 전체 + 한식페스타(`festaApp_*`) 규칙. 기존 앱 규칙은 그대로예요.
> 규칙을 고치면 `python3 build-rules-page.py` 로 `rules.html` 을 다시 만들어 주세요.

### 2. 깃허브 페이지로 공개
1. 이 저장소 → **Settings → Pages**
2. Source: `Deploy from a branch`, Branch: `main`(또는 이 작업 브랜치) / `/ (root)` → Save
3. 1~2분 뒤 `https://yeri099-oss.github.io/NMK/` 주소로 접속

### 3. 최초 로그인
- 관리자 아이디 `goodbab` 과 정해둔 관리자 비밀번호로 로그인하면 관리자 계정이 자동으로 만들어지고,
  기본 상품 10가지(귤당근쥬스, 레몬즙, 김부각, 새송이부각, 수승대발효 1년장, 아미산쑥티 1년장, 제주푸른콩 1년장, 귀한 3년 간장, 귀한 10년 간장, 보자기카스테라)가 자동으로 등록됩니다.
- 일반 계정은 **[관리] 탭 → 계정 관리**에서 만들어 주세요.

## 화면 구성

화면 아래 탭바로 이동해요. 가운데 동그란 **＋** 버튼이 판매 화면이에요.

| 탭 | 기능 |
|---|---|
| **판매** | 왼쪽: 상품 한 줄씩(수량 −/+)과 선택한 상품. 오른쪽: 맨 위 **↻ 초기화**(초록)·**판매 등록**(빨강), 고객정보, 결제방식(카드/현금/QR), 받은 현금 → 거스름돈, 상품 합계·결제 금액(＋ 할인 버튼을 누르면 원/% 입력칸), 비고 |
| **상품정보** | 사진·설명·가격을 한국어/English로 보기. 상품을 누르면 사진과 설명이 한 화면에 크게 보임 |
| **대시보드** | 전체 합계 / 10.23 / 10.24 별. 첫 줄 매출·건수·객단가, 둘째 줄 카드·현금·QR 매출, 셋째 줄 상품별 판매수량 카드(화면 너비에 맞춰 한 줄). 아래에 날짜별·상품별·결제방식별·시간대별·국적·성별 표 |
| **판매내역** | 번호·판매상품·결제금액·결제방식·내·외국인·성별·판매시간. 상품/결제방식/내·외국인/성별 카드를 눌러 골라 보기, 제목 누르면 정렬, 줄을 누르면 수정·삭제, 엑셀(CSV) 받기 |
| **관리** (관리자만) | 상품 추가·수정·삭제(사진 업로드 포함), 계정 만들기·권한 변경·사용중지, 연습 데이터 정리 |

## 고객용 상품 소개 (QR)
- 주소: `https://yeri099-oss.github.io/NMK/menu.html` — 로그인 없이 상품 사진·가격·설명만 보여요 (한국어/English).
- 매대용 포스터: `qr-menu-poster.png` (QR만: `qr-menu-code.png`). [관리] 탭에도 버튼이 있고, 직원 누구나 [상품정보] 탭의 "고객용 QR 보여주기"로 화면에 QR을 띄울 수 있어요.
- [관리]에서 상품을 고치면 고객용 페이지에도 바로 반영돼요.
- 접속 수: 대시보드 "고객 QR 상품소개 접속"에 날짜별 접속 수(한국어/English)와 상품별 상세 조회 수가 보여요. 같은 사람이 새로고침해도 한 번만 세요 (`festaApp_stats`).

## 세트 할인 (자동)
- 부각 3개(김부각·새송이부각 섞어도 됨) 12,000원, 귤당근쥬스 2개 9,000원 / 5개 20,000원.
- 담은 수량에 맞춰 가장 싼 조합을 자동으로 계산하고, 결제 금액 상자에 초록색 "세트 할인"으로 표시돼요. 직접 할인은 세트 할인 뒤에 추가로 적용돼요.
- 세트 가격을 바꾸려면 `index.html` 의 `SET_RULES` 를 고쳐주세요.

## 알아두면 좋은 점
- **앱처럼 쓰기:** 아이패드/아이폰 Safari로 앱 주소를 열고 **공유(□↑) → 홈 화면에 추가**를 누르면 홈 화면 아이콘으로 주소창 없이 열려요. (안드로이드 크롬: ⋮ → 홈 화면에 추가)
- **버전:** 화면 맨 위 작은 글씨줄에 버전(예: v46)이 보여요. 새 버전이 올라오면 위에 **🔄 새 버전 · 눌러서 업데이트** 버튼이 떠요. 코드를 고치면 `index.html` 의 `APP_VERSION` 을 올려 주세요.
- **인터넷이 없어도 앱이 열리고 판매 등록이 됩니다.** 한 번 인터넷으로 열어두면 앱 화면이 기기에 저장돼요(`sw.js`). 판매는 각 기기에 먼저 저장되고(상단에 "업로드 대기 N건"), 그 기기가 인터넷에 연결되면 자동으로 올라가요. 업로드 전에 그 기기의 앱을 지우거나 브라우저 데이터를 삭제하면 안 돼요. 로그인은 인터넷이 될 때 미리 해두세요.
- 행사 전에 연습한 판매는 대시보드의 **행사일 외**로 따로 보이고, [관리] → **행사일 외 판매내역 삭제**로 한 번에 지울 수 있어요.
- 상품별 매출은 **정가 기준**이고, 할인은 합계 아래에 따로 빠져서 **실매출**로 표시돼요.
- 상품 설명은 초안이에요. [관리] → 상품 **수정**에서 실제 내용으로 고쳐주세요.
- 사진은 자동으로 줄여서 저장돼요(파이어베이스 Storage 불필요).
- 일반 계정 비밀번호를 잊으면 사용중지 후 새 아이디로 만들어 주세요.
