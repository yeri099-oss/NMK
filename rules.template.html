🔐 파이어베이스 규칙 복사 도우미

기존 앱 규칙 전체 + 한식페스타 매출 앱 규칙이 합쳐진 전체 규칙이에요. 통째로 바꿔 넣으면 돼요.

  1. 아래 복사하고 규칙 화면 열기를 누르세요. (규칙이 복사되고, 파이어베이스 규칙 화면이 새 탭으로 열려요)
  2. 규칙 편집창을 한 번 클릭하고 Ctrl+A (맥은 ⌘+A)로 기존 내용을 전부 선택
  3. Ctrl+V (맥은 ⌘+V)로 붙여넣기
  4. 오른쪽 위 게시 버튼 클릭 → 끝!

파이어베이스 보안상 붙여넣기(3번)와 게시(4번)는 직접 눌러야 해요. 다른 곳에서 규칙을 따로 고친 적이 있다면 이 내용으로 덮어쓰기 전에 알려주세요.
